# Como participar

Você não precisa programar para ajudar.

## Se você usa (ou usaria) o Publicare

- **Conte o que você precisa.** Abra uma [proposta](https://github.com/publicare/publicare4/issues/new?template=proposta.md) dizendo qual problema quer resolver (por exemplo: "preciso de uma consulta pública com cadastro"). Descrever a situação ajuda mais do que descrever a solução.
- **Teste e relate.** Se algo não funcionar, abra um [problema](https://github.com/publicare/publicare4/issues/new?template=problema.md) com os passos para repetir. Capturas de tela ajudam.
- **Tem um site no Publicare antigo?** Conte como ele é (tamanho, o que usa). Isso orienta o importador. **Não** publique dados de terceiros nem endereços internos de órgãos.

## Se você escreve ou ensina

- Melhore a [documentação](../README.md): erro de português, passo que faltou, explicação que ficou difícil. Pode abrir o PR direto.
- Traduza ou revise os guias desta pasta.

## Se você programa

Leia o [guia de colaboração](../../CONTRIBUTING.md) e a [documentação técnica](../tecnica/README.md).

## Se você achou uma falha de segurança

Não publique. Siga a [política de segurança](../../SECURITY.md).

## Acompanhe

- Código e discussões: <https://github.com/publicare/publicare4>
- O que muda a cada versão: [CHANGELOG](../../CHANGELOG.md)

Ao participar, você aceita o [Código de Conduta](../../CODE_OF_CONDUCT.md).

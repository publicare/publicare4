# Trilha do desenvolvedor

Esta trilha é para quem **constrói em cima do Publicare**: peles e moldes, tipos de conteúdo, cargas de dados, scripts e a linha de comando (`bin/pbl`).

Por onde começar: [Tipos de conteúdo](tipos-de-conteudo.md) (o modelo de dados), [Peles e modelos de página](peles-e-moldes.md) e, em seguida, a [linguagem PBL4](pbl4-visao-geral.md), com um capítulo inteiro para os moldes. Para automação, veja [Agentes e scripts](agentes-e-scripts.md). Quem vem do Publicare antigo encontra em [Migrando do PBL3](pbl4-migrando-do-pbl3.md) o que mudou, comando a comando.
